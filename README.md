# Yacht Claims MVP

A lightweight MVP for yacht claim management with:
- internal Work Hub
- yacht overview
- claim detail
- customer access
- supplier claim portal
- multilingual-ready UI

## Local development

1. Install dependencies:
   npm install
2. Set environment variables:
   cp .env.example .env
3. Run app:
   npm run dev
4. Open: http://localhost:3000
